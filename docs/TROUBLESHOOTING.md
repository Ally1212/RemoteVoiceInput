# 原理、排障与验收记录

本机豆包输入法 → 本机原生文本框 → 苹果屏幕共享原连接。
不要求豆包发送可识别的粘贴事件，不在远端安装软件。

## 原理

可以把工具理解成一个“文字中转站”，不是远程麦克风：

1. 豆包先把语音识别成文字，输入本机的小窗。
2. 用户确认发送，工具先把这段文字写入本机剪贴板。
3. 工具再切回原来的屏幕共享连接，让系统同步剪贴板。
4. 等待约 1.5 秒，再通过系统事件发送一次 Command+V。

也就是：本机听写，系统传文字，远端粘贴。不向远端传麦克风，也不自动提交。

## 使用

1. 打开应用，点“授权”，在系统设置的辅助功能里允许“远程语音输入”。
2. 在苹果屏幕共享“编辑”中勾选“使用共享的剪贴板”，收起菜单，点击远程输入框。
3. 点屏幕右上方的“语音输入”悬浮按钮，弹出本机输入窗。
4. 用你原来的豆包语音快捷键说话。文字应出现在本工具的输入框里。
5. 文字定稿后按 `Command + Enter` 并松开。工具回到原连接，等待系统同步剪贴板，再粘贴一次。

无需快捷键也可以使用。看不到悬浮钮时，在本工具中点“选远程位置（3秒）”，
再在三秒内点击远程输入框，小窗会自动回来。
悬浮钮是非激活窗口，点击时先捕获仍在前台的远程连接，再激活输入窗。
输入窗适配当前桌面和全屏辅助窗口。全局快捷键 `⌘L` 可打开输入窗。
快捷键注册结果和触发事件通过系统 Logger 记录，不记录输入文字。

首次联调请用远程“文本编辑”的空白文档，不要直接在终端或业务系统测试。
建议先退出 Remote Dictate Helper，减少两个桥接工具同时工作的干扰。
本应用不会自动关闭或卸载其他软件，也不会修改豆包设置或注册登录项。

## 行为与限制

- 第一版有本机接收窗和一次确认，不是完全无界面的直接远程听写。
- 支持简体中文、繁体中文和英文屏幕共享菜单；其他语言会明确失败。
- 不录音、不做语音识别、不调用网络接口、不保存听写历史和正文日志。
  豆包自身的语音处理方式不受本工具控制。
- 草稿只保存在进程内存，退出后消失。
- 发送会替换本机剪贴板并保留待发送文字，不自动恢复之前复制的内容。
- 只读取共享剪贴板的勾选状态，不自动打开菜单、不切换共享设置。
  请先手动开启共享；关闭时会提示设置，不发送粘贴指令。
- 粘贴通过 macOS“系统事件”的单次 `key code 9 using {command down}` 操作发送，
  不自行拼装修饰键事件。首次需要允许本应用自动化控制“System Events”。
  发送前等待确认快捷键或鼠标完全松开，再校验原连接和前台进程。
- 菜单栏提供“本机粘贴自检”：使用隔离的本机文本框验证实际插入结果，
  不发送到远程，不改草稿，并在剪贴板没有被其他程序修改时恢复其原内容。
- 发送失败会显示输入窗中的具体原因。重新打开已收起的输入窗会清空文字；可按 ⌘K 手动清空。
- 不播放“成功”提示音，因为发出本机指令并不等于远端已收到。
- 捕获本机的屏幕共享连接窗口，不读取远端控件。远程光标必须由用户事先放好。
- 发送前校验连接窗口、前台应用、剪贴板文字和新输入；不在更换的窗口重试。
  系统同步可能改变剪贴板版本但保留相同文字，因此不因版本单独变化而取消。
- 先写本机剪贴板，再激活原连接，然后等待约 1.5 秒供共享剪贴板同步。
  实机对照发现激活后才写入会贴出上一轮内容；不能只靠延长等待解决。
  没有远端送达确认接口，慢网络下仍可能不成功。
  不再使用本机探针或声称远程核验通过。请以远端实际显示为准，不要盲目重复发送。
- 只发粘贴，不发 Enter。工具无法保证远端应用对粘贴内容的处理方式，
  多行文本请勿未经检查发送到终端、数据库控制台等会执行命令的界面。
- 公司电脑的剪贴板限制、安全策略或辅助功能限制不能由本工具绕过。

## 构建与测试

需要 macOS 13+ 和 Swift 6 工具链。

```sh
swift test
zsh scripts/build.sh
```

启动全新应用、尚未选定远程目标且草稿为空时，可验证原生输入窗：

```sh
osascript scripts/ui-smoke.applescript
```

该检查只在本机文本框里写入并清除测试文字，不发送、不写剪贴板。

产物：`dist/RemoteVoiceInput.app`，不是公证发行包。
构建优先使用钥匙串中已有的 Apple Development 身份，保持更新前后的授权身份稳定。
可用 `RVI_SIGN_IDENTITY` 指定身份；没有开发身份时回退到 ad-hoc 签名，
这种情况下重新构建后可能需要重新授予辅助功能权限。切换签名身份本身也需要重新授权。

## 手动验收

1. 无权限：提示授权，不修改剪贴板，不发送按键。
2. 不在屏幕共享：提示先选定远程输入框。
3. 本机输入框：键入、粘贴、豆包语音均应能输入。
4. 远程空白文本编辑：发送中文、英文、多行文本，核对内容只出现一次。
5. 共享设置：开启时发送，关闭时提示用户手动设置；工具不改变原状态。
6. 发送等待期间切换应用、点击或复制：取消且不向新窗口粘贴。
7. 关闭原连接：发送失败，不选择其他连接。
8. 极快重复确认：最多一次发送；工具不自动重试。
9. 失败后输入窗显示具体原因并保留文字；收起后再次打开会清空文字。
